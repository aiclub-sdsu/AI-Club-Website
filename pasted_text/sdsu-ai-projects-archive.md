Theme: Sentiment Analysis & Hackathon Challenges
Project Name
Description
Drive Artifacts
Yelp Review Sentiment Prediction
Predicted star ratings and overall sentiment of Yelp reviews using GloVe 50d embeddings and an LSTM neural network (Keras/TensorFlow). Built a custom BeautifulSoup web scraper for data collection. Achieved ~90% accuracy on unseen reviews.
Final Presentation Slides
Project Outline Doc
AskReddit Post Evaluator (AI-A-THON)
Hackathon project: LSTM binary classifier that predicts whether a Reddit post will reach the front page. Used GloVe 100d embeddings. When confidence threshold set to 0.75, achieved 88% precision.

Spring 2026
Theme: Agentic AI, Computer Vision (YOLO), Quantitative Finance, Medical AI, Recommendation Systems
Project Name
Description
Drive Artifacts
Regime Adaptive Market Intelligence System
Detect stock market regimes (high/low volatility, trending/mean-reverting) using Hidden Markov Models, extract stable return factors per regime via PCA, and signal alpha decay when factor correlations drop below a threshold. Walk-forward validation used for evaluation. Includes optional stretch features like Autoencoders and dynamic strategy switching. (Easy–Medium, Quant Finance focus)
Spring 2026 Projects Breakdown Doc
Project Ideas PDF
Assignment Deadline Manager
Agentic system that integrates with the Canvas LMS API to deliver smart, automated reminders based on assignment difficulty, time to completion, and student procrastination patterns. Uses LLMs for summarizing and semantic analysis. Optional: full-stack React frontend. (Easy–Medium)
Spring 2026 Projects Breakdown Doc
AI Health Assistant
An agent that takes in a patient health report and outputs a series of probable diagnoses. LLMs are used only for summarizing — inference is handled by trained models to avoid hallucination risks. Health parameters are team-defined. (Easy–Medium)
